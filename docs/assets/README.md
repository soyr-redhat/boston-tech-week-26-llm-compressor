## Image Guidelines

- Format: PNG or WebP (PNG preferred)
- Size: Max 2MB per image
- Resolution: 1200x600px or similar aspect ratio
- Style: Professional, technical diagrams
- Colors: Match Red Hat branding (reds, blacks, grays)
